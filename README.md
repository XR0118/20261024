# 闻声起跳 · LoudLeap

2026 七牛第五届 1024 Hackathon · 研发赛道 · 议题 6（灵矽应用：语音类游戏）

一款声控横版跳跃游戏：**喊得越响，跳得越高**。灵矽 AI 是游戏的大脑——
开场主持、按主题动态生成关卡、金币经济与全语音商店、以及一个会根据你的
表现实时嘴炮并跟你猜数字对决的 AI Boss。

## 玩法全景

1. **待命**：语音唤醒后说「开始游戏」，主持人倒计时开局。
2. **跑酷**：角色自动前进，声音实时驱动——响度=跳跃力度，空中持续喊=喷气推进；
   拾取金币（入账=余额），避开坑与警示横杆。
3. **语音商店**：结算回首页后说「换个造型」，用余额购买/切换角色造型（跳跳豆免费 /
   声波精灵 20 金币），全程语音、无 UI 操作。
4. **Boss 战**：跑完全程进入与挑战者的猜数字对决（Bulls & Cows）——语音报数，
   Boss 全中触发攻击 QTE，喊声格挡；胜利本局金币翻倍。
5. **复盘**：局终写入灵矽长期记忆，教练人格基于历史表现点评。

美术为夜空霓虹主题，全部程序化矢量绘制，**零图片素材**。

## 灵矽分层架构（demo 可逐级降级）

| 层 | 能力 | 灵矽链路 |
|----|------|---------|
| L0 | 本地声控跳跃（麦克风响度 → 跳跃/喷气力度） | 无，纯本地 <50ms |
| L1 | 语音主持 + 结算点评 + 记忆复盘 | 灵矽 ASR/TTS + 第三方应用接入 |
| L2 | 按主题动态生成地图（LLM 产关卡 seed） | 第三方应用接入 |
| L3 | AI Boss：实时嘴炮 + 猜数字对决 + 攻击格挡 | 第三方应用接入 |

架构决策详见 [docs/adr/](docs/adr/)（双通道架构、golang 设备端点、Boss 战语音阶段）。

## 语音指令表

| 指令 | 阶段 | 效果 |
|------|------|------|
| 「你好小智」 | 待命 | 唤醒 |
| 「开始游戏」（含「开始」「来一局」） | 待命 | 主持人倒计时开局 |
| 「换个造型」 | 待命 | 购买/切换角色造型（全语音商店） |
| 「成绩」「点评」 | 待命 | 教练复盘播报 |
| 「换地图」「换关卡」 | 待命 | 换 seed 重生成地图 |
| 报三位数字（如「一二三」） | Boss 战 | 上报密数 / 报数试探 |
| 「投降」 | Boss 战 | 认输结算 |
| 大喊（无语义） | 跑酷/格挡 QTE | 跳跃/喷气/格挡 |

## 快速开始

后端（灵矽链路 + 游戏状态机 + 钱包/Boss 引擎）：

```bash
cd server
go run .        # :8080；灵矽连接需要预注册设备的 MAC（见 server/main.go）
```

前端（游戏本体）：

```bash
cd web
npm install
npm run dev     # 默认 5197；浏览器授权麦克风
```

可选环境变量：`LINGX_API_KEY` / `LINGX_MEMORY_ID`（教练复盘记忆写入）。
空格键为无声控调试通道（跳满档、直进 Boss 战入口在首页）。

## 测试

```bash
cd server && go test ./...
cd web && npm test        # vitest：关卡不变量/QTE/bossui/麦克风
```

